# Sentient Partners: Opus 5.5 Design Kit

Single-package handoff for the homepage redesign. This kit contains original user reference photos, selected simplified design comps, the approved founder/brand foundation, eight-card capability specs, project design rules, and one Opus implementation instruction.

**Fast path:** Extract this package as `<repo>/design-foundation/`, then paste `design-foundation/implementation/PASTE_INTO_OPUS.md` into Opus 5.5. The prompt preserves any existing `CLAUDE.md` and local redesign work.

The files under `references/design-comps` are **inspirational nonfunctional image mockups**; reproduce their visual direction, not their incidental generated text. Original photographs are primary source references. Confirm third-party copyright/license and suitable attribution before publishing images.

Includes:
- `CLAUDE_ADDENDUM.md`: persistent project guardrails
- `CAPABILITY_CARDS.md`: eight-card interaction and content architecture
- `implementation/PASTE_INTO_OPUS.md`: single comprehensive build prompt
- `brand/`: brand foundation PDF and editable DOCX
- `references/original-photography/`: bridge, redwoods, Auburn images
- `references/design-comps/`: three cleaned concept images
